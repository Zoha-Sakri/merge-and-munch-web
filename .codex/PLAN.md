# Web Full Game Plan

Build an original responsive farming-city game in React/TypeScript. The feature loop is crops and cattle -> merge production -> citizen orders -> coins/stars/happiness -> buildings/restaurants/decorations/wonders -> Ancient City expeditions.

Keep state in the existing Web reference patterns, contracts in `shared/`, and rule coverage in `tests/`. Add crop/animal states, order requirements and patience, building upgrades, happiness, exploration depth, local-save schema migrations, onboarding, accessibility, and clear popup/icon states.

Typography is Fredoka for headings and Nunito Sans for UI. Preserve responsive behavior and original Merge & Munch content. Never copy Farm City branding, artwork, text, characters, maps, or exact progression.

Validate with `npm test && npm run build` and `git diff --check`.
