# Web Agent Guide

Merge & Munch Web is the playable reference for an original farming-city game: grow crops, collect cattle goods, merge ingredients, serve orders, upgrade buildings, decorate the town, and explore Ancient City tunnels.

Keep content original; do not reproduce Farm City branding, art, text, characters, maps, or exact progression. Use the existing React/TypeScript patterns and preserve responsive small-screen behavior.

Validate with `npm test && npm run build`. Keep gameplay state connected to the farm -> merge -> trade -> build loop.
